BTL 16 - HE THONG DAU GIA TRUC TUYEN THOI GIAN THUC
====================================================

DAY LA FULL PROJECT JAVA DESKTOP:
- 1 TCP server trung tam
- nhieu Swing client
- login/session/account
- danh sach va phong dau gia
- bid dong thoi, broadcast realtime
- timer server, anti-sniping, ket thuc phien
- reconnect/resume/resync
- Laragon MySQL database btl_16

A. CHAY NGAY KHONG CAN MYSQL
----------------------------
1. Cai JDK 17 tro len.
2. Double-click: 01_TEST_KHONG_CAN_MYSQL.cmd
3. Double-click: 02_DEMO_NGAY_KHONG_CAN_MYSQL.cmd
4. Dang nhap cac client:
   demo/demo123
   alice/alice123
   bob/bob123

B. CHAY VOI LARAGON + MYSQL
---------------------------
1. Bat MySQL trong Laragon, port 3306.
2. Kiem tra config/server.properties:
   db.name=btl_16
   db.user=root
   db.password=
3. NetBeans/VSCode phai load Maven de tai MySQL Connector/J.
4. Double-click: 03_TAO_DATABASE_LARAGON.cmd
5. Double-click: 04_CHAY_SERVER_LARAGON.cmd
6. Moi may client double-click: 05_CHAY_CLIENT.cmd

C. CHAY TRONG LAN
-----------------
- May server giu server.bindAddress=0.0.0.0 va mo Windows Firewall TCP 8888.
- May client sua config/client.properties:
  client.serverHost=IPv4_CUA_MAY_SERVER
- Client KHONG ket noi truc tiep MySQL 3306.
