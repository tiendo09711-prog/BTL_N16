BTL 16 - SAN DAU GIA REALTIME JAVAFX + WEBSOCKET
=================================================

KIEN TRUC HIEN TAI
------------------
- JavaFX desktop client la mac dinh.
- WebSocket ws://127.0.0.1:8890/ws la transport mac dinh.
- TCP 127.0.0.1:8888 duoc giu cho legacy/test/console/load-test.
- Mot Java server trung tam xu ly session, room, bid, timer va MySQL.
- Client khong ket noi MySQL truc tiep.

A. CHAY NHANH TREN MAY SERVER
-----------------------------
1. Cai Node.js, JDK 17+, Maven va MySQL/Laragon.
2. Mo terminal tai thu muc goc.
3. Chay: npm run dev
4. Runner build, migrate DB, start TCP + WebSocket va mo JavaFX client local.
5. Nhan Ctrl+C de dung server/client.

Tai khoan demo:
   demo/demo123
   alice/alice123
   bob/bob123

B. CAC LENH NPM
---------------
npm run dev
npm run dev:server
npm run dev:server -- --skip-setup
npm run client
npm run client -- --url=ws://IP_SERVER:8890/ws
npm run client -- --transport=tcp --host=IP_SERVER --port=8888
npm test
npm run dist:client

C. CHAY TRONG LAN
-----------------
- May server bind 0.0.0.0 va mo firewall TCP 8890; mo 8888 neu demo legacy.
- May client mo packaged JavaFX app-image va nhap ws://IP_SERVER:8890/ws.
- May client khong can source, IDE, Maven, Node hay JDK.
- ws:// la WebSocket endpoint, khong phai website.
- Khong mo MySQL 3306 cho client.

D. PACKAGED CLIENT
------------------
Chay: npm run dist:client

Ket qua:
   dist\BTL16-Auction-Client\

Copy ca thu muc nay sang may Windows khac va mo BTL16-Auction-Client.exe.
