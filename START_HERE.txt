BTL 16 - HE THONG DAU GIA TRUC TUYEN THOI GIAN THUC
====================================================

DAY LA FULL PROJECT JAVA DESKTOP:
- 1 TCP server trung tam
- nhieu Swing client
- login/session/account
- danh sach va phong dau gia
- bid dong thoi, broadcast realtime
- timer server, anti-sniping, ket thuc phien
- phong dong con hien 120 giay, sau do tu an khoi san; lich su van luu MySQL
- reconnect/resume/resync
- Laragon MySQL database btl_16

A. CHAY NHANH TREN MAY SERVER
-----------------------------
1. Cai Node.js, JDK 17, Maven va Laragon.
2. Mo terminal tai thu muc goc.
3. Chay: npm run dev
4. Runner se kiem tra MySQL, build, setup DB, chay server va mo mot client local.
5. Nhan Ctrl+C de dung server/client.
6. Dang nhap:
   demo/demo123
   alice/alice123
   bob/bob123

B. CAC LENH NPM
---------------
npm run dev                         server + mot client local
npm run dev:server                  chi server
npm run dev -- --skip-setup         khong setup/seed lai DB
npm run client -- --host=IP_SERVER  chay client toi may server

C. CAU HINH MYSQL
-----------------
Kiem tra config/server.properties:
   db.name=btl_16
   db.user=root
   db.password=

Project khong con che do repository thay the va khong con script tu dong mo nhieu cua so.
Server khong tu tao du lieu demo; chi lenh `02_TAO_DATABASE_MYSQL.cmd` thuc hien setup/seed.

D. CHAY TRONG LAN
-----------------
- May server giu server.bindAddress=0.0.0.0 va mo Windows Firewall TCP 8888.
- May client chay: npm run client -- --host=IPv4_CUA_MAY_SERVER
- Client KHONG ket noi truc tiep MySQL 3306.
- Chi may server can truy cap MySQL.
- Dia chi IP:8888 la TCP, khong phai link trinh duyet.
